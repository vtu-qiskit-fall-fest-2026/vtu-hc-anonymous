## Project Description

Q-Lithos is an interactive quantum-chemistry dashboard that uses Qiskit's Variational Quantum Eigensolver (VQE) to explore molecular energies and compare VQE results with a classical exact-diagonalization reference.

**Execution note:** The current workflow uses a local ideal statevector simulator; this link does not imply execution on physical IBM Quantum hardware.
